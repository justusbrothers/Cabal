Upload CSV to Add/Update Part Parameters

This tool lets you bulk-add or update part parameters using a simple CSV.
Required column: IPN (matches Internal Part Number)
All other columns become parameter names with their cell values as data.

{% csrf_token %}
Example CSV:
IPN,Name,Creators: Writer,Creators: Penciller,Creators: Inker
CB-001,Spider-Man #1,Stan Lee,Steve Ditko,Terry Austin
CB-002,Batman: Year One,Frank Miller,David Mazzucchelli,Richmond Lewis

Tips:
• Parameter templates are created automatically if they don't exist.
• Existing parameters are updated if the IPN + parameter name already exists.
• Empty cells are saved as empty strings (you can leave optional fields blank).
